### ☕ About Me (No Corporate Fluff)

```text
Name     : Rafli Alif
Day Job  : Telecommunications Engineering student at ITS Surabaya
Side Gig : Lab Assistant at Telecommunication Network Laboratory (TNL)
Routine  : Writes code -> breaks build -> stares at screen -> fixes typo -> profit
Motto    : If it compiles, ship it. If it doesn't, blame the cache.
```

I study telecom engineering, tinker with radio navigation, set up local networks, and build web apps when I'm bored. No "10x rockstar ninja enterprise" nonsense here — just an engineering student who enjoys making cool software and figuring out how things work under the hood.

### 📦 Things I Actually Built

| Project | What it actually does | Stack |
| :--- | :--- | :--- |
| 🛰️ **[SIMULORAN](https://github.com/rhaffle87/SIMULORAN)** | Loran-C & eLoran navigation simulator. Because satellite GPS is too mainstream and ground-waves at 100 kHz are cool. | `React` `TypeScript` `Vite` |
| 🛡️ **[FCL-Research-Study](https://github.com/rhaffle87/FCL-Research-Study)** | Federated learning for network traffic analysis. Teaching models to spot threats without snooping on private data. | `Python` `PyTorch` |
| 👁️ **[SeeNOW](https://github.com/rhaffle87/SeeNOW)** | Autonomous browser agent with Playwright CDP. It clicks buttons on the web so my fingers don't have to. | `Python` `Playwright` |
| 🌐 **[S4RAS](https://github.com/rhaffle87/S4RAS)** | Offline server and network kit for remote areas. Bringing LMS and media where the internet fears to tread. | `TypeScript` `Docker` `VoIP` |
| 💸 **[Cukupin](https://github.com/rhaffle87/Cukupin)** | Personal finance tracker. Specifically built to guilt-trip myself into not ordering more iced coffee. | `Next.js` `Supabase` `Tailwind` |
| 📍 **[presensi-extension](https://github.com/rhaffle87/presensi-extension)** | Browser extension injecting custom coordinates to attendance portals. Purely for geographical experiments, obviously. | `JavaScript` `Extension` |
| 🎨 **[actife](https://github.com/rhaffle87/actife)** | Simple interactive ML visualizer. Making neural nets look less like scary math and more like fun dots. | `React` `JavaScript` |
