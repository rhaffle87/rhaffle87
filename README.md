### 🌐 Overview

I build resilient systems at the intersection of **Radio-Frequency (RF) Physics**, **Cyber Defense**, and **Modern Full-Stack Architectures**. My current work focuses on GNSS-resilient alternative Positioning, Navigation, and Timing (PNT), decentralized federated learning for encrypted traffic intrusion detection, and high-concurrency distributed web platforms.

- 📡 **Radio-Navigation & Propagation:** Engineering solvers and simulators for Loran-C / eLoran, hyperbolic TDOA multilateration, GDOP optimization, and ITU-R ground-wave propagation standards.
- 🛡️ **Cyber Defense & Telemetry:** Researching federated continual learning (FCL) for zero-day encrypted traffic IDS, Byzantine robustness, and SOC/SOAR threat simulation platforms.
- ⚡ **Autonomous Agents & Tooling:** Developing low-latency browser automation agents (Playwright CDP, Set-of-Marks visual grounding) and network telemetry workflows.
